DAW Agent MCP

Local Rust MCP daemon plus a VST3 / CLAP / AU plugin shell. This site is a landing page only — the daemon binds 127.0.0.1 and is not hosted on Vercel.

Downloads

Plugin bundles ship from GitHub Releases (tag v* runs the Release workflow). AU is macOS-only.

Run locally

  • cargo run -p daw-mcp -- --host=reaper
  • Connect Claude Code / Cursor / Codex as an MCP stdio server
